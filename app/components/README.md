# App Components

This directory contains reusable React components for the Drop Predator Shopify app.

## Component Structure

- Place shared UI components here that can be used across multiple routes
- Keep components focused and single-purpose
- Use proper TypeScript/PropTypes validation
- Follow the existing naming conventions

## Examples

Common components that might be added here:
- Button variants
- Form inputs
- Data tables
- Loading states
- Modal dialogs
- Cards and panels
