# React Hooks

This directory contains custom React hooks for the Drop Predator app.

## Available Hooks

Common hooks that might be added here:
- useDebounce - Debounce values
- useLocalStorage - Persist state to localStorage
- useMediaQuery - Responsive design utilities
- useAsync - Handle async operations
- useOnClickOutside - Handle clicks outside elements

## Usage

Import hooks from this directory:
```javascript
import { useDebounce } from '../hooks/useDebounce';
```
