# E2E Tests

This directory contains end-to-end tests for the Drop Predator app.

## Test Structure

Place end-to-end tests here that simulate real user interactions across the application.

## Test Categories

- User flows (drop creation, activation, etc.)
- Integration tests with Shopify APIs
- Cross-browser compatibility tests
- Performance tests

## Running E2E Tests

```bash
npm run test:e2e
```

## Requirements

- E2E test framework (e.g., Playwright, Cypress)
- Test environment configuration
- Shopify test store setup
